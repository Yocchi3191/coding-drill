# coding-drill

週1回、1時間で解く実装課題の練習用リポジトリ。面接の持ち帰り課題と同じ形式（仕様付き、時間制限付き、採点付き）を、繰り返し練習する。

## 流れ

1. 土曜の8:00に、Claudeが課題を出題する。問題文HTMLを `problems/` に追加して push する。
2. 日曜の8:00〜9:00に、公開された問題文を開いて解く。画面のカウントダウンタイマーが締切を示す。
3. 9:00になったら、そこまでの状態を質問係のClaudeセッションに見せる。
4. 質問係が、[coding-drill プラグイン](https://github.com/Yocchi3191/yocchi-plugins)の `grade` skill で採点し、`feedback/` にFBを書く。

## 構成

| パス | 内容 |
|---|---|
| `problems/` | 問題文HTML。課題ごとに `<日付>_<題材>/index.html`。このフォルダだけを Cloudflare Pages で公開する |
| `templates/problem.html` | 問題文HTMLの雛形（カウントダウンタイマー付き） |
| `docs/problem-rules.md` | 出題ルール。出題タスクが読む |
| `feedback/` | FBドキュメント。課題ごとに `<課題名>.md`。公開しない |

## 公開範囲

Cloudflare Pages で公開するのは `problems/` だけにする（出力ディレクトリを `problems` に指定する）。`feedback/` や `docs/` は公開しない。

問題文HTMLのHTMLコメントには、採点側に渡す情報（クリティカルなエラー、軽微なエラー、質問するケース）が入っている。リポジトリは公開で、公開サイトのソース表示でも見えるため、解く前にソースを開かないこと。

## 解いた成果物

成果物は、このリポジトリには置かない。課題ごとに別のリポジトリを作る（解いたあとの記念として、作り方は自由）。
