# ネタ

出題の題材の候補。1行に1センテンスで書く。詳細を詰めたものは、`docs/topics/<名前>.md` に置き、行の末尾にリンクを付ける。

詳細には、仕様のどこまで、規模、触らせたい論点を書く。クリティカルなエラーと軽微なエラーは書かない。解く人が先に知ってはいけないので、出題タスクが考える。

仕様を実装する課題だけを対象にする（調査型の課題は、いまは対象外）。

- 書籍の貸出管理のDB設計とAPI
- 掲示板の一覧API（ページネーション）
- クーポンを適用する価格計算API

- ファイルアップロードの進捗管理API
