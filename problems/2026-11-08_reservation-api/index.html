会議室の予約管理API

概要

社内の会議室を予約するWeb APIを作る。同じ会議室の同じ時間帯に、複数の予約が入らないようにすることが、この課題の中心である。

仕様

データ

  • 会議室：ID、名前、定員を持つ。会議室の一覧は、あらかじめ数件を用意しておいてよい。
  • 予約：ID、会議室、予約者（社員ID）、開始日時、終了日時、人数、状態（有効／キャンセル済み）を持つ。

機能

  1. 予約の作成：会議室、予約者、開始日時、終了日時、人数を受け取り、予約を登録する。
  2. 予約のキャンセル：予約を指定してキャンセルする。キャンセルした枠は、他の人が予約できるようになる。
  3. 予約の一覧：会議室と日付を指定して、その日の有効な予約を、開始日時の順に返す。
  4. 空き会議室の検索：開始日時、終了日時、人数を指定して、その時間に空いていて、定員が足りる会議室を返す。

ルール

  • 同じ会議室で、時間帯が重なる有効な予約は、登録できない。
  • 予約の時間は、15分単位とする。
  • 営業時間は、毎日8:00〜20:00とする。
  • 1人が持てる、未来の有効な予約は、最大5件とする。
  • 複数の利用者が、同時にAPIを呼ぶことを想定する。

成果物

  • APIが動く実装。データの保存方法は自由（永続化は必須ではない）。
  • データの構造（テーブルなど）と、APIのエンドポイントの設計が、説明できる状態にする。

制約

  • 制限時間は1時間。終わらなくてもよい。時間になったら、そこまでの状態を質問係に見せる。
  • 言語、フレームワーク、DBは自由。選んだ根拠は、あとで聞かれる。
